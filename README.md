# Breast Cancer of Aisslab V5

This repository contains the Breast Cancer of Aisslab V5 dataset organized into two versions:

## Dataset Structure

```text
Breast-Cancer-of-Aisslab-V5/
│
├── Raw/
│   └── Original breast cancer images
│
├── augmented/
│   └── Augmented breast cancer images
│
└── README.md
````

## Description

### Raw

Contains the original breast cancer ultrasound images collected for classification tasks.

### Augmented

Contains augmented versions of the original images generated using image transformation techniques such as rotation, zooming, flipping, and shearing to improve model generalization.

## Applications

* Breast Cancer Classification
* Deep Learning Research
* Transfer Learning
* Medical Image Analysis
* Computer-Aided Diagnosis (CAD)
